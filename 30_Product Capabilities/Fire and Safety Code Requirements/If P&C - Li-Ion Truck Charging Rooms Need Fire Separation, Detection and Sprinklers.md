# If P&C - Li-Ion Truck Charging Rooms Need Fire Separation, Detection and Sprinklers

## Definition

One insurer's hazard sheet says that where lithium-ion truck charging is attached to a building it needs EI60 fire separation, automatic fire detection and sprinklers, and that indoor charging is generally not recommended.

## Notes

- **Insurer guidance, not a code.** It shows what one insurer asks, not what any authority requires; tagged `regulatory-driver` only so the vault gates treat it as external (decision pending with the owner; see the register).
- Jurisdiction not stated in the retrieved text; units and fire class suggest Europe. US relevance unknown (IB-278).
- Second-hand reading; see [[Lithium Forklift Charging Area Fire and Safety Code Register]] and [[If P&C Insurance]].
