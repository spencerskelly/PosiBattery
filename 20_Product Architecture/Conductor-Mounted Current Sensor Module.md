# Conductor-Mounted Current Sensor Module

## Definition

Module installed around an existing conductor that outputs a signal proportional to conductor current.

## Notes

The module must support the required DC current range when used on industrial traction batteries. Exact magnetic technology, aperture size, and signal interface remain product-specific.
