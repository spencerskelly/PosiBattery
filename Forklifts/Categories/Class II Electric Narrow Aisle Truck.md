# Class II Electric Narrow Aisle Truck

## Definition

Electric motor narrow aisle trucks: reach, order picker, turret and similar trucks for tight aisles.

## Notes

- OSHA describes Class II as electric motor narrow aisle trucks. Source: OSHA eTool and OSHA class definitions sheet (T1/T2), retrieved 2026-10-03. <https://osha.prod.pace.dol.gov/etools/powered-industrial-trucks/types-fundamentals/types> and <https://www.navsup.navy.mil/Portals/65/NAVSUP%20ENTERPRISE/NAVSUP%20FLC%20Pearl%20Harbor/Documents/MHE_Class_Definitions_OSHA.pdf>
