# Class I Electric Rider Truck

## Definition

Electric motor rider trucks: counterbalanced stand-up, three-wheel sit-down, and counterbalanced rider with cushion or pneumatic tires.

## Notes

- Lift codes include counterbalanced rider stand-up, three-wheel electric sit-down, counterbalanced rider cushion tires and counterbalanced rider pneumatic tires. Source: OSHA eTool and OSHA class definitions sheet (T1/T2), retrieved 2026-10-03. <https://osha.prod.pace.dol.gov/etools/powered-industrial-trucks/types-fundamentals/types> and <https://www.navsup.navy.mil/Portals/65/NAVSUP%20ENTERPRISE/NAVSUP%20FLC%20Pearl%20Harbor/Documents/MHE_Class_Definitions_OSHA.pdf>
