# USB Battery Data Export

## Definition

PC data-export path using removable USB storage or a USB-connected transfer adapter.

## Notes

- [[Philadelphia Scientific eGO!Mini]] explicitly stores data on a removable USB drive.
- [[Power Designers PowerTrac DT3]] explicitly uploads to a PC through a PowerTrac Link USB device.
- [[USB Data Download]] remains the transport/interface Design; this Design represents the export workflow carried over it.
