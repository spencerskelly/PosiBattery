# Base Vault Version

- **Release:** 2026-09-20
- **Purpose:** clean reusable MDSE model starter for engineer/AI-assisted early model development
- **Schema basis:** ruleset 1.18
- **Project content:** none; only reusable methodology, schemas, templates, plugins, dashboards, import governance, and disposable generic examples

## Key methodology updates

- explicit type-vs-instance specialization test;
- model-wide control classification;
- evidence-first / no-assumption rule;
- stakeholder journeys separated from Use Cases and product Functions;
- concrete-first external Interface and Item Flow modeling;
- forward-authored relationships with persisted generated inverses;
- Breadcrumbs and Canvas relationship visibility;
- product Functions require controlled performers and justified Requirements;
- behavior-first Function navigation;
- fewer-than-25 modeled elements per immediate folder using real semantic splits only;
- required guide/Base/Canvas package for model-facing folders;
- AI instructions optimized for broad, reviewable initial coverage rather than false completeness.
