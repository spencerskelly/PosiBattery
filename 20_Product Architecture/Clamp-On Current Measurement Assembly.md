# Clamp-On Current Measurement Assembly

## Definition

Current measurement assembly using a sensor installed around an existing conductor without opening the conductor path.

## Notes

For traction-battery DC current, the selected sensor must support DC measurement. The exact magnetic implementation and signal interface remain product-specific.
