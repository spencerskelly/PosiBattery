# Verify PosiGuard Lead-Acid and Lithium Application Support

## Definition

Verification intent to demonstrate that PosiCharge PosiGuard supports its defined monitoring and integration role for the supported lead-acid and supported lithium industrial battery applications identified by the product requirements.

## Notes

- This verification is PosiGuard-specific and must not be generalized to earlier BMID generations.
- Supported lithium BMS protocols, CAN messages, responsibility boundaries, and the exact supported application set remain open detail requirements.
- No approved Procedure, Setup, Plan, or executed Result is currently available in the governed model.
- A later Procedure must use the supported battery/application matrix defined by controlled requirements rather than market-language assumptions.
