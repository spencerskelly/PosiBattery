# Metric - Equalizing Charge Rule

## Definition

Equalizing Charge Rule: when and how an equalizing charge is done

## Notes

- **Code and class:** BM15; battery metric. Unit or format: when and how an equalizing charge is done.
- **Comparability rule:** Cadence (time or event) and current limit are different statements; record both.
- **Direction:** not ranked.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[HAWKER Perfect Plus Battery]]: after deep discharges, repeated incomplete recharges and charges to an IU characteristic curve; current not above 5 A per 100 Ah of rated capacity; watch temperature
  - [[Deka D-Series Battery]]: every one to four weeks (charger set to the equalize position); specific gravity read after the equalize
  - [[Deka MaxPowr Battery]]: every one to four weeks; specific gravity recorded monthly after an equalize
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** Add Stryten and HOPPECKE; the Exide Industries manual gives 3 percent of capacity in amperes as the starting current (snippet).
