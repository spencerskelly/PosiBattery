# Document - Oregon DEQ Energy Economy Ratio Values Table (2022-05-16)

## Definition

DEQ's 2022 table of Oregon energy economy ratios, with electric forklift 3.8.

## Notes

**How it was read:** through a summarizing fetch tool (second-hand), not the raw file.

Added in the 2026-10-17 web research round. DEQ file named EERadjustedCIs that holds Table 7 EER values; the only date is the publication date of 2022-05-16, so it predates the 2023 expansion rules.

- **Forklift rows:** electric forklift 3.8 (heavy-duty/off-road, diesel replacement); fuel cell forklift 2.1; propane forklift 0.9. Other rows include battery electric vehicle 3.4 (light/medium duty), 5.0 (heavy-duty), transit bus 5.0, eTRU 3.4, cargo handling equipment 2.7, ocean-going vessels 2.6.
- **Compare:** the same forklift values appear in the 2025 rule attachment ([[Document - Oregon DEQ Rule Attachments OAR 340-253-8010 Tables 4 7 and 9 (effective 2025-01-09)]]); no change found between them.
- **Tier 2 route:** the file describes applying for a new EER (see OAR 340-253-0460 in [[Document - OAR 340-253-0460 Cornell LII Page (retrieved 2026-10-17)]]).
