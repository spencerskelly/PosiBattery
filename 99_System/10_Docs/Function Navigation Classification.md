# Function Navigation Classification

## Principle

Function folders are organized by **behavioral type before impacted domain**.

Primary categories:
1. Capability Groups
2. Acquire and Input
3. Maintain and Transform
4. Evaluate and Decide
5. Search and Resolve
6. Present and Publish
7. Coordinate and Transact
8. Integrate and Exchange
9. Govern and Administer
10. Measure and Monitor

## Decision rule

Classify a Function by its primary behavioral verb and state change.

Examples:
- calculate/classify/determine → Evaluate and Decide;
- publish/render/serve → Present and Publish;
- synchronize/export/import across a boundary → Integrate and Exchange;
- review/approve/authorize → Govern and Administer.

Folder placement is navigation only. It does not define semantic inheritance, ownership, affected domain, or product scope.

A second behavioral subfolder level is permitted only when both:
- the category approaches/exceeds the 25-element ceiling; and
- the split reflects a durable intrinsic distinction in the behavior.
