# Product Functions

## What is here

Reusable behaviors that battery monitoring and charger-interface products perform, such as measuring voltage, sensing electrolyte level, identifying a battery to a charger, or uploading data to a portal.

## What belongs here

One Function note per distinct behavior. A product is linked with `performs` only where a source states the behavior. No Requirements are linked, so these Functions show as unsatisfied in model checks by design.
