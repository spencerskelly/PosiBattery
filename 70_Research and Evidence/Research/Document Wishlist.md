## Definition

Running list of documents identified as useful, what each would fill, and whether it has been received, so the owner can add them to the repo.

## Notes

- **Row order and columns (owner requests, rounds 15 and 17):** Status (high priority, helpful, issue, in repo; a second line gives detail), Document, and URL, which now holds a direct file address only. Where no direct file has been found the cell says so and a separate 'Where to look' column holds a page; company home and landing pages are removed. Rows run high priority (newest first), helpful (medium before low), issue, in repo.
- **How it works:** the owner downloads a listed document into the repo (folder Downloads); the next round absorbs it into a Document note, checks it against other sources, and logs differences as conflicts. New useful documents found during any search are added here.
- **Status words:** absorbed = in the repo and read into notes; received, not yet absorbed = in the repo, queued; direct link found = a direct file address was found by search but nothing is in the repo yet; wanted = no direct file address yet; bad link = the owner could not download it.
- **Link types:** direct file = the address ends in a file name or sits in a downloads path; page = a web page that may link a file; landing or home page = not a download, listed only until a file address is found. Tables avoid the pipe character inside cells (it split rows in an earlier version).
- **Layout from round R74 (2026-10-18, owner request):** the table is split into three sections. Section 1 holds rows added in the latest rounds. Section 2 holds files already in the repo that have not been absorbed. Section 3 holds files still wanted, in priority order: high priority, then helpful (medium before low), then issue rows. Within each priority the newest round comes first, as in the earlier row-order rule; this is the only ordering inside a priority, so it is not a ranking by decision impact. Rows for files that are in the repo and already read and absorbed moved verbatim to [[Reviewed Documents Register]]; nothing was deleted. This supersedes the row order described above.
