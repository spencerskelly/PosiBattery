# Stryten AGM220 Onboard Charger

## Definition

Delta-Q smart high-frequency charger built into the Stryten AGM220, with auto start/stop and an I-E-I (CC-CV-CC) profile.

## Notes

- **Update 2026-10-14 (priority 5, unlinked-product review):** linked to [[Charge Battery]], [[Indicate Charger Status Locally]] because the brochure describes an automatic on-board charger with an LED display of status and recharge time. Source: as cited on this note.
- **Update 2026-10-14:** the battery link changed from partOf to integratesWith, following the owner decision of 2026-10-14 for battery-to-charger links (C227/C229); the brochure says the charger is on board, not that it is a battery component.
- **Working name given by the analyst; Stryten gives no model name or number.** Fully automatic on-board Delta-Q HF charger; 25 A constant start rate; auto start/stop; LED display of status and recharge time; optional temperature compensation; international versions available. Source: Stryten AGM220 brochure SE1043 and Pow'r Pak LD page (T1, second-hand), <https://www.stryten.com/wp-content/uploads/2023/03/Stryten_M-SeriesProductBrochure_AGM220_SE1043_FINAL.pdf>; <https://stryten.com/marathon-powr-pak-ld/>
- Input AC voltage and output rating not stated; Delta-Q model not named (IB-186). Maker attribution comes from the brochure and product page wording "Delta-Q".
