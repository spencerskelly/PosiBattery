# MDSE Base Vault — Ruleset 1.18

A domain-neutral Obsidian starter for lightweight Model-Driven Systems Engineering.

Open this folder directly in Obsidian, then begin at [[00_Home/MDSE Home]].

The package includes:
- current MDSE ruleset and metamodel;
- AI instructions for evidence-first initial modeling;
- templates and FileClass schemas;
- bidirectional relationship synchronization and Breadcrumbs navigation;
- Canvas relationship projection;
- behavior-first Function navigation;
- folder/Base/Canvas conventions and 25-element ceiling;
- verification model;
- generic engineering examples;
- import governance for external models.

The vault intentionally contains **no project/domain model**. The `98_Examples` folder is disposable and exists only to demonstrate modeling mechanics.
