# PC Service Tool Software

## Definition

Technician-facing desktop or laptop software used to configure, inspect, diagnose, or retrieve logs from a battery-connected device.

## Notes

- This Object represents the generic PC-side software role rather than a specific commercial application.
- Product-specific tools may support Bluetooth, USB, serial, NFC-reader, or other service connections.
- Exact operating system support, update workflow, file formats, and authentication remain product-specific.
