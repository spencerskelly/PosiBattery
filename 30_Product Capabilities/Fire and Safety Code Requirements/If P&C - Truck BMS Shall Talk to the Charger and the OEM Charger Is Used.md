# If P&C - Truck BMS Shall Talk to the Charger and the OEM Charger Is Used

## Definition

One insurer's hazard sheet says lithium trucks should have a smart BMS that communicates with the charger to set the correct maximum level and charge rate, and that the truck maker's (OEM) charger should be used.

## Notes

- **Insurer guidance, not a code.** The OEM-charger clause cuts against any third-party or multi-brand charger positioning; how strictly an insurer enforces it is unknown (IB-278).
- Charger-side consequence: REQ-00077 (analyst-proposed).
- Second-hand reading; see [[Lithium Forklift Charging Area Fire and Safety Code Register]].
