# Metric - Equalize Scheduling

## Definition

Equalize Scheduling: how the charger schedules an equalizing charge

## Notes

- **Code and class:** CM21; charger metric. Unit or format: how the charger schedules an equalizing charge.
- **Comparability rule:** Cadence and who triggers it; the charge itself is described in the battery's rules.
- **Direction:** not ranked.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[EnerSys IMPAQ Charger]]: weekly equalize can be programmed; time should be scheduled after the equalize for cooling when opportunity charging is used
  - [[EnerSys NexSys+ Charger]]: weekly equalize; external EQUALIZE input
  - [[PosiCharge ProCore Edge]]: extended low-current charge once a week after a regular charge to 100 percent; EQ button during the EQ window; set by charger or BMID
  - [[PosiCharge DVS150]]: equalization scheduling (public page)
  - [[Crown V-HFM3 Charger]]: indicators show equalizing and watering needs; schedule not stated
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** Add Fronius, Delta-Q (equalize FAQ exists), Crown schedule details.
