# Verify BMID Battery Condition Information Delivery

## Definition

Verification intent to demonstrate that a supported PosiCharge BMID configuration makes the required supported battery-condition information available to a compatible charger.

## Notes

- The exact condition data set must come from the applicable product requirement or child-product refinement.
- This verification does not assume that every BMID generation reports current, electrolyte level, state of charge, CAN data, or another specific quantity.
- No approved Procedure, Setup, Plan, or executed Result is currently available in the governed model.
- Product-specific verification must identify the concrete BMID variant and required data set before execution.
