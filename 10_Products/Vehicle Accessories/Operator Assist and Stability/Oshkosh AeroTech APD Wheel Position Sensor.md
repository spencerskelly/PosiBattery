# Oshkosh AeroTech APD Wheel Position Sensor

## Definition

APD sensor that warns the operator when the wheels are not centered on selecting reverse, and can disable reverse if an aircraft is in short radar range.

## Notes

**Summary:**
Oshkosh AeroTech APD sensor that monitors cargo-loader wheel position to prevent sideways movement when backing away from aircraft.

**Marketed features:**
- Visual and audible warning if wheels are not centered when reverse is selected
- Can disable reverse if an aircraft is in short radar range and wheels are not centered
- Modular APD sensor installation for multiple configurations
- APD configurable to IATA AHM 913 anti-collision guidance
