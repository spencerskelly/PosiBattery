# Jungheinrich Reverse Area Warning System

## Definition

Jungheinrich rear-area device that warns by light and sound, stronger as a detected object gets closer.

## Notes

**Summary:**
Jungheinrich rear-area warning device that alerts the operator with light and sound that intensify as an object gets closer.

**Marketed features:**
- Monitors the area behind the vehicle
- Optical and acoustic warnings to the operator
- Warning intensity and volume vary with object distance
