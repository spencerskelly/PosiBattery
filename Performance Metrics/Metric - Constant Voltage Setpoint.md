# Metric - Constant Voltage Setpoint

## Definition

Constant Voltage Setpoint: volts per cell at a stated temperature

## Notes

- **Code and class:** BM22; battery metric. Unit or format: volts per cell at a stated temperature.
- **Comparability rule:** Compare only at the same reference temperature (20, 25 or 30 C) and for the same design (flooded, AGM, gel).
- **Direction:** not ranked.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[Stryten M-Series AGM220 Battery]]: 2.37 V per cell (constant-voltage portion of a CC-CV-CC profile; reference temperature not stated)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** East Penn gives 2.40 to 2.43 V per cell at 20 C for its AGM 8A line and ZVEI 2.35 V per cell at 30 C for PzV gel; those are not traction product notes; add Stryten AGM200 and AGM210, Hoppecke and Exide PzV values.
