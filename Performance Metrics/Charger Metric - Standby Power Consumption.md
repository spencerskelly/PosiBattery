# Charger Metric - Standby Power Consumption

## Definition

Standby Power Consumption: Power drawn while the charger is idle.

## Notes

- **Code and class:** CM16; charger metric. Unit or format: W.
- **Comparability rule:** Compare only with the same measurement conditions; the EnerSys figure is a portfolio statement.
- **Direction:** lower is better.
