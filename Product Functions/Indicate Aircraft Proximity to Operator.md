# Indicate Aircraft Proximity to Operator

## Definition

Show the operator how close the vehicle is to the aircraft, for example with colored lights.

## Notes

- GSE-side behavior found in product descriptions. Product links only where a source states the behavior.
- No Requirement is linked (intentional gap).
- **Sources** (product, evidence level, web page):
