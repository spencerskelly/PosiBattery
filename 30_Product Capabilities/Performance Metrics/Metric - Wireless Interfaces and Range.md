# Metric - Wireless Interfaces and Range

## Definition

Wireless Interfaces and Range: Radio interfaces and quoted range.

## Notes

- **Code and class:** MM08; monitor metric. Unit or format: radio; range.
- **Comparability rule:** Quoted range is usually open-air and vendor stated; BLE and Zigbee are not directly comparable.
- **Direction:** n/a.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[AMETEK Prestolite Power WBID]]: ZigBee up to 500 ft (152 m) truck-mounted (obsolete)
  - [[Advanced Charging Technologies BATTview]]: Wi-Fi (range n/s)
  - [[Crown V-Force BMID]]: Bluetooth Class 1 (range n/s)
  - [[EnerSys Wi-iQ]]: Zigbee 2.4 GHz about 10 m; BLE about 5 m
  - [[EnerSys iQ Mini]]: wireless to iQ Gateway (radio n/s in flyer)
  - [[HOPPECKE trak collect]]: NFC; Bluetooth 4.0 LE and 2.0 (data sheet); earlier note: NFC 16 mm; Bluetooth 4.0 Low Energy / 2.0
  - [[Philadelphia Scientific eGO!gateway]]: Bluetooth about 70 m; 4G/3G/2G
  - [[PosiCharge PosiGuard]]: Bluetooth, WiFi, LoRa (sheet); earlier note: Bluetooth; LoRa (range n/s)
  - [[Power Designers PowerTrac 3]]: 900 MHz industrial wireless; up to 150 ft (sheet; equals DT3, C47)
  - [[Power Designers PowerTrac DT3]]: 900 MHz; up to 150 ft (46 m)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
