# Remote Charger Control Panel

## Definition

Operator-facing wired remote panel that presents charger status and accepts local charger control inputs from a location away from the charger enclosure.

## Notes

- The Crown V-HFM3 kit explicitly includes a wired remote control mounted on a pole with a detachable cable.
- Exact buttons, display elements, indicators, enclosure, mounting, and command set are not published in the current evidence.
