# EnerSys BSI40

## Definition

EnerSys battery status indicator that shows the operator the next battery to use (first-in, first-out) from charger status.

## Notes

- Digital display of the next available battery; optional alarm for wrong battery selection; remote view and control of charge cycles (complete, incomplete, equalise); RS 485. Works with select Hawker chargers. Source: EnerSys BSI40 page (T1, second-hand), <https://www.enersys.com/en-gb/products/monitoring-and-fleet-management/network-and-softwares/enersys/bsi40>
- Linked to IRONCLAD because the IRONCLAD guide lists BSI40 as a monitoring option (U-level link from DOC for IRONCLAD guide).
- The page names Hawker chargers, not EnerSys-branded ones, and mentions a "BSI software program" for reports; not modeled separately (IB-183). Charger models not stated.
- Added from a generic option name ("BSI40") in the IRONCLAD guide; the product page was then found.
