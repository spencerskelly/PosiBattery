# Fire and Insurer Review - Charger Shall Accept an External Interlock and Stop Charging When It Trips

## Definition

The charger shall accept an external interlock input (for example fire alarm or ventilation failure) and stop charging when it trips.

## Notes

- **Analyst-proposed.** Derived from an insurer's ask (REQ-00073); no customer, code or buyer was seen requiring it of a charger. No acceptance value (response time, contact type) is proposed.
- Candidate function: [[Start and Stop Charge from an External Control]]. Whether the existing charger designs already provide this input is not checked here.
- See [[Lithium Forklift Charging Area Fire and Safety Code Register]].
