# Exide Element VRLA Battery

## Definition

Exide Element gel battery blocks for light-duty motive power, introduced with the Element HF charger in 2007.

## Notes

- Exide's 2007 release describes Element battery blocks with gelled electrolyte for maintenance lifts, people movers and walkie trucks, unified with Element HF chargers. Source: The Auto Channel (2007) (T2 (dated)), retrieved 2026-10-02. <https://www2020.theautochannel.com/news/2007/03/28/041598.html>
