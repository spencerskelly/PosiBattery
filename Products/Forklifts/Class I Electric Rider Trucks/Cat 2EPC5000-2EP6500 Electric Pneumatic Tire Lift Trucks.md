# Cat 2EPC5000-2EP6500 Electric Pneumatic Tire Lift Trucks

## Definition

Cat electric pneumatic tire lift trucks with operator presence detection, travel speed reduction and a lithium-ion option.

## Notes

- A Cat brochure (in a trade-show directory) lists an operator presence detection system, travel speed reduction, an electric heater, a raised operator cab, a fully floating operator cabin and a lithium-ion battery package for the 2EPC5000-2EP6500 series.
