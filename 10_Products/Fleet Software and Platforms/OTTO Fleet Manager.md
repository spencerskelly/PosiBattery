# OTTO Fleet Manager

## Definition

OTTO software that assigns AMRs to jobs, with charging scheduled around idle time.

## Notes

- A dealer page describes a Smart Charging Strategy (recharge during idle periods), battery level as one factor in task assignment, and automatic assignment of AMRs. Source: [[Document - Wajax OTTO Fleet Management Software Page (retrieved 2026-10-14)]] (T2). <https://wajax.com/?p=72138>
- The page does not name the maker; the maker is taken as [[OTTO Motors]] from the product name (C264).
