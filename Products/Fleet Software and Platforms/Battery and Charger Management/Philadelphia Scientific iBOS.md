# Philadelphia Scientific iBOS

## Definition

Philadelphia Scientific iBOS battery management system with Charger-Splitter and Battery Tracker modules.

## Notes

- MHI's profile calls iBOS the Intelligent Battery Organizing System, and the MODEX 2020 listing says the web interface was improved to integrate the latest Charger-Splitter and Battery Tracker iBOS modules. Source: MHI member profile and MODEX 2020 listing (T1/T2), retrieved 2026-10-03. <https://2020.modexshow.com/listing.aspx?id=46059>
- **Name overlap (C73):** an iBOS module is called Battery Tracker, as is the Hyster Battery Tracker; no source links them.
