# Document - Green Cubes SAFEFlex PLUS UL Listing Press Release (2025-08-15)

## Definition

Green Cubes press release of 2025-08-15 announcing UL listing and EE rating for the whole Lithium SAFEFlex PLUS family (24, 36, 48 and 80 V).

## Notes

**How it was read.** Through a fetch tool that returns a model-written summary, not the raw text, on 2026-10-13. The tool itself said the table layout was garbled and that some column assignments were inferred, so per-class values below are unverified until the raw file is read (IB-168).

- Announced 2025-08-15 (Kokomo, IN); page last modified 2025-09-29. Covers 24, 36, 48 and 80 V models. Names no UL standard and does not define EE.
- Features: UL-recognized module with functional safety; state-of-charge monitoring and balancing; modular cell blocks and a battery control module for field replacement; sized for standard lead-acid compartments and truck weight requirements. The original Lithium SAFEFlex line continues to be sold.
- No capacities. Quotes are from CEO Michael Walsh.
- An earlier release of 2024-09-27 on Power Systems Design (<https://www.powersystemsdesign.com/articles/green-cubes-technology-announces-ul-listing-with-ee-rating-for-lithium-safeflex-plus/8/22082>) announced SAFEFlex PLUS with a UL listing for the **48 V family** and mentions no other voltage (C214).
