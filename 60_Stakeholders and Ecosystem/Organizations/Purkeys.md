# Purkeys

## Definition

Maker of the Purkeys trailer auxiliary power system listed as an accessory of the Raymond 8250 walkie pallet jack.

## Notes

- **Role (working label):** Accessory Maker.
- Raymond's 8250 page lists the Purkeys system as an accessory that converts DC to AC so the truck can charge inside a delivery trailer; Purkeys is a third-party supplier to Raymond, and no other Purkeys product was researched. Source: Raymond 8250 page (T1, second-hand), retrieved 2026-10-14. <https://raymondcorp.com/forklifts/pallet-trucks/8250-lithium-ion-pallet-jack>
- Created 2026-10-18 so the product has an identifiable company; resolves the missing-maker note IB-191.
