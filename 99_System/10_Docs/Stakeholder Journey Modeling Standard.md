# Stakeholder Journey Modeling Standard

## Purpose

Use stakeholder journeys to understand the full end-to-end experience without prematurely assigning all behavior to the modeled product.

## Journey definition

A stakeholder journey may cross:
- multiple Actors;
- organizations;
- manual handoffs;
- external products/systems;
- the modeled product;
- contextual operations.

## Rule

A journey is broader than a Use Case.

For each step, classify the step as one or more of:
- product-controlled behavior;
- modifiable/shared behavior;
- contextual/external behavior;
- manual human handoff;
- candidate Interface / Item Flow;
- candidate Use Case;
- candidate Requirement;
- candidate failure mode/question.

Only promote a step into product scope when responsibility and evidence justify it.
