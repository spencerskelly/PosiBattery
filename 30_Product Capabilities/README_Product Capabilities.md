# Product Capabilities

## Purpose

This is the canonical PosiBattery domain for product intent and measurable behavior: Functions, Requirements, Properties, Performance Metrics, States, Failure Modes, and Verification records.

See [[Canonical Vault Top-Level Taxonomy 0.1]] and [[PosiBattery Model Organization and Handoff]].

## Current capability areas

- [[README_Product Functions|Product Functions]] — what products, systems, or subsystems do.
- [[README_Product Designs|Product Designs]] — reusable technical solution concepts; this area remains a migration candidate for later classification.
- [[README_Performance Metrics|Performance Metrics]] — reusable dimensions used to characterize and compare products, designs, and outcomes; this area remains subject to later classification review.

Present folder placement does not override later semantic classification or migration decisions.

## Navigation

- `BASE_local_Product Capabilities.base` — direct Markdown contents of this domain.
- `BASE_all_Product Capabilities.base` — recursive Markdown contents across the capability domain.
- [[CANVAS_Product Capabilities]] — curated map of the three major capability areas.

## Scope guidance

Use this domain for stable capability definitions and measurable behavior. Architecture and realization content belongs under [[README_Product Architecture|Product Architecture]] when that is its primary role.

Do not move Product Designs or Performance Metrics solely for visual consistency. Later classification steps control any semantic relocation.
