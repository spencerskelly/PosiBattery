# Report Truck Hours and Usage

## Definition

Send a truck's operating hours and usage to a fleet portal so use can be analyzed.

## Notes

- Split from [[Report Truck Telemetry]] on 2026-10-14 so that only products whose sources state hours or usage claim it.
- Stated: Linde lists connect:an usage analysis and operating hours (source on [[Linde connect]]); Logisnext says Lift Link captures hour meters and usage in real time (source on [[Logisnext Lift Link]]); STILL says FleetManager offers reports and telematics applications that monitor the use of trucks and drivers on site (source on [[STILL FleetManager]]).
- Need links are analyst reasoning. No Requirement is linked.
