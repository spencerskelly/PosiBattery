# Document - Electrical Contractor Magazine Whats Classified as an Electric Vehicle (2015-05-06)

## Definition

Trade-press code quiz explaining that off-road self-propelled electric vehicles, including industrial trucks, are not "electric vehicles" under NEC Article 625.

## Notes

**How it was read:** through a summarizing fetch tool (second-hand). Read once.

- **Claim:** the definitions section (625.2) excludes off-road, self-propelled electric vehicles such as industrial trucks (forklifts), so Article 625 does not treat them as electric vehicles.
- **Not stated:** the NEC edition; which Article does govern forklift battery chargers (the tool found none named).
- **Dated:** 2015. The current NEC text for 625.2 and for storage battery rules was not read (IB-276).
- **Disagreement:** a forum thread on a forklift charging station feeder has one poster applying 625.42 (continuous load) and another citing the 625.2 exclusion; the thread does not resolve it ([[Lithium Forklift Charging Area Fire and Safety Code Register]], sources list; C320).
