# Fire and Insurer Review - Charger Shall State the Listing Standard and Edition It Is Certified To

## Definition

Charger documentation shall state the listing standard and edition the charger is certified to (for example UL 1564 and its edition), so a fire authority or insurer can judge "approved type".

## Notes

- **Analyst-proposed.** Derived from "approved type" (REQ-00064). Vault sources rarely give the edition a charger is certified to; UL 1564 status is itself in dispute (C316) and the standard's lithium coverage is unknown.
- No external body was seen asking for the edition; the value is traceability for a reviewer.
- See [[Lithium Forklift Charging Area Fire and Safety Code Register]].
