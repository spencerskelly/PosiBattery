# Class VII Rough Terrain Forklift

## Definition

Rough terrain forklift trucks for unimproved surfaces (context only).

## Notes

- OSHA describes Class VII as rough terrain forklift trucks, a generic term for forklifts intended for use on unimproved natural terrain. Source: OSHA eTool and OSHA class definitions sheet (T1/T2), retrieved 2026-10-03. <https://osha.prod.pace.dol.gov/etools/powered-industrial-trucks/types-fundamentals/types> and <https://www.navsup.navy.mil/Portals/65/NAVSUP%20ENTERPRISE/NAVSUP%20FLC%20Pearl%20Harbor/Documents/MHE_Class_Definitions_OSHA.pdf>
