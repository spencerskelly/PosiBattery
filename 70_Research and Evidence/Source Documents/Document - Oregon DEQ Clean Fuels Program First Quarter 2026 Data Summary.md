# Document - Oregon DEQ Clean Fuels Program First Quarter 2026 Data Summary

## Definition

Oregon DEQ's Q1 2026 program summary, charts only, with no prices or forklift figures in the extracted text.

## Notes

**How it was read:** first-hand, from the raw file the owner added to the repo (`Downloads/ODEQ_cfpq12026.pdf`), with text extracted by pdftotext. Not a summary.

Added from the owner's downloads. Two-page DEQ quarterly data summary with charts of credits, deficits and the bank (Q1 2016 to Q1 2026) and credits by fuel type.

- **Text content:** electricity credits are 'increasing steadily as the electric vehicle population in the state increases'. Residential EV credits are calculated twice a year and appear in the Q2 and Q4 summaries.
