# Metric - Charge Profile Types Offered

## Definition

Charge Profile Types Offered: named profiles or characteristics the charger offers

## Notes

- **Code and class:** CM19; charger metric. Unit or format: named profiles or characteristics the charger offers.
- **Comparability rule:** Names are maker-specific and not interchangeable; compare what each profile is for, not the label.
- **Direction:** not ranked.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[EnerSys IMPAQ Charger]]: P21 STDWL (IUI), P22 HDUTY (pulse with current loops), P19 FAST (airmix), P07 OPP (finish current 5 percent), P25 LOWCHG, NexSys TPPL P31 NXBLOC, P29 NXSTND, P30 NXFAST; IEI, gel IEI, O and IEIE letter types
  - [[EnerSys NexSys+ Charger]]: same profile code family as IMPAQ, with a unique TPPL profile
  - [[Delta-Q IC650]]: lead-acid (wet, AGM, gel) and lithium algorithms; up to 25 field-programmable; each lead-acid algorithm is Bulk, Absorption and Finish
  - [[Crown V-HFM3 Charger]]: Conventional, Opportunity, Fast and V-Force Lithium-Ion
  - [[Fronius Selectiva 4.0]]: Ri characteristic; special characteristic for opportunity and fast charging; refresh; deep discharge
  - [[PosiCharge ProCore Edge]]: PosiCharge proprietary algorithms in BMID mode or voltage mode (names not published in the retrieved text)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** Numeric stage values (voltages per cell, currents, termination) are not published by these makers in the retrieved text; add them when a charger manual or profile list gives them; add Exide, Stryten, Hoppecke, ACT and Delta-Q profile lists.
