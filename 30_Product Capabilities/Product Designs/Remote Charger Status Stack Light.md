# Remote Charger Status Stack Light

## Definition

Charger-status indication using a tower or stack light positioned away from the charger face so charge state or fault state can be seen from a distance.

## Notes

- [[Crown V-HFM3 Tower Light Kit]] is an LED tower-light kit with an I/O expansion board and mounting hardware.
- [[PosiCharge Three-Color Stack Light]] uses green for charged, yellow for charging, and red for not charging or fault; PosiCharge states that it requires an Accessory Driver Kit.
- The two products establish the shared remote stack/tower-light pattern, but their electrical interfaces are not assumed to be identical.
