# Metric - Charge Factor

## Definition

Charge Factor: ratio of ampere-hours charged to ampere-hours discharged

## Notes

- **Code and class:** BM21; battery metric. Unit or format: ratio of ampere-hours charged to ampere-hours discharged.
- **Comparability rule:** Stated for a given depth of discharge and temperature; electrolyte circulation lowers it.
- **Direction:** lower is better for water use and energy.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[HAWKER Perfect Plus Battery]]: 1.07 with the electrolyte circulation system (manual)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** ZVEI gives 1.2 as the standard charging factor for vented PzS, about 1.07 with air mix, 1.17 for Wsa chargers and 1.1 for gel PzV (no product notes); add other makers.
