# Folder Organization

Folders are a human navigation and automation layer; **YAML type/relationships are authoritative**. The numbered prefixes keep the model in a useful engineering order.

The top-level structure follows the current MDSE schema: Things → Interfaces/Flows → Context → Functions/behavior → states → Requirements/Design → Use Cases/Actors → failure/issues/info → verification → documents/artifacts.

`90_Concept` is intentionally non-authoritative workspace. `90_Concept/AI_Workspace` is the default AI write area. Promote material into model folders only after review. `98_Examples` is disposable. `99_System` holds the methodology and tooling.
