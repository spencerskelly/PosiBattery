# Wired Remote Charger Control Assembly

## Definition

Reusable charger accessory assembly that relocates charger control and status functions to a wired remote panel.

## Notes

- Typical implementation includes a remote operator panel, cable/harness, and charger-side I/O expansion or interface electronics.
- The Crown V-HFM3 kit directly supports this assembly abstraction.
- Exact electrical signaling and connector pinout remain product-specific.
