# Load-Handling Image Sensor Module

## Definition

Camera sensor and optical module that converts the viewed load-handling scene into image data.

## Notes

- This Object is intentionally generic and does not assert CMOS versus CCD, resolution, lens type, illumination, or image-processing capability.
- Event triggering and image retention are handled by separate reusable architecture Objects.
