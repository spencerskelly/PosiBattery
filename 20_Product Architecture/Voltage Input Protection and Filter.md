# Voltage Input Protection and Filter

## Definition

Protection and signal-conditioning network between the battery-voltage input and the measurement ADC.

## Notes

Typical elements can include series impedance, RC filtering, clamps/TVS devices, and input protection selected for the battery transient environment.
