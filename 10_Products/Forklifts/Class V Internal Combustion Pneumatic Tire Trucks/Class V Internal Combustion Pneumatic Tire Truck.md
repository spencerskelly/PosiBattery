# Class V Internal Combustion Pneumatic Tire Truck

## Definition

Internal combustion engine trucks on pneumatic tires (context only).

## Notes

- OSHA describes Class V as internal combustion engine trucks with pneumatic tires. Source: OSHA eTool and OSHA class definitions sheet (T1/T2), retrieved 2026-10-03. <https://osha.prod.pace.dol.gov/etools/powered-industrial-trucks/types-fundamentals/types> and <https://www.navsup.navy.mil/Portals/65/NAVSUP%20ENTERPRISE/NAVSUP%20FLC%20Pearl%20Harbor/Documents/MHE_Class_Definitions_OSHA.pdf>
