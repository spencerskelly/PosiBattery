# Metric - Peak Efficiency

## Definition

Peak Efficiency: Highest AC-to-DC conversion efficiency.

## Notes

- **Code and class:** CM04; charger metric. Unit or format: %.
- **Comparability rule:** Peak and full-cycle efficiency differ; vendor claims are not tested figures.
- **Direction:** higher is better.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[ACT Quantum 2]]: over 94% peak (sheet); earlier note: over 94%
  - [[ACT Quantum 3]]: 96.4% peak (requires high-efficiency module); earlier note: over 96.4%
  - [[ACT Quantum Outdoor]]: over 94%
  - [[AMETEK Prestolite Power Eclipse II]]: 93%
  - [[Crown V-HFM3 Charger]]: up to 97% (Crown claim)
  - [[Deka PowerForce Charger]]: about 95%
  - [[EnerSys IMPAQ Charger]]: up to 94% (guide)
  - [[EnerSys NexSys+ Charger]]: 94% with NexSys iON; '94% or greater' (chart)
  - [[Lester Summit Series II]]: above 91% peak (DOE test, 115 Vac)
  - [[Power Designers REVOLUTION X]]: above 93% (2017) or above 92% (REVOLUTION X page) (C35)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** 7 product(s) have a value; document-based values to be added as documents are supplied.
