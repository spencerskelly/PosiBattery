# Metric - Float Voltage per Cell

## Definition

Float Voltage per Cell: volts per cell

## Notes

- **Code and class:** BM19; battery metric. Unit or format: volts per cell.
- **Comparability rule:** Float or storage charging only; not part of a shift charge.
- **Direction:** not ranked.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[HAWKER Perfect Plus Battery]]: 2.27 V per cell for storage as an alternative to a monthly equalizing charge
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** GNB (Exide Technologies) EPzS manual says 2.23 V per cell (see conflict C97); no GNB product note exists for it yet.
