# Metric - Detection Range and Accuracy

## Definition

Detection Range and Accuracy: Stated detection range, field of view or location accuracy.

## Notes

- **Code and class:** TM02; truck device metric. Unit or format: ft or m; field of view; accuracy.
- **Comparability rule:** Range versus location accuracy are different quantities; field of view needs an angle.
- **Direction:** longer range or finer accuracy.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[Blaxtair Pedestrian Detection System]]: customizable detection zone; vendor says ISO recommends latency under 300 ms (ideally 200 ms) and claims under one false alarm a day
  - [[Crown ProximityAssist System]]: detection zone length adjusts with travel speed; range not stated
  - [[Hyster Pedestrian Awareness Camera]]: up to 16 ft; 110 degree field of view
  - [[IRIS 860 Sensor Pack]]: detection zone customizable up to 8 m
  - [[Linde Safety Guard]]: location accuracy up to 10 cm (pilot report)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison.
- **Gaps and to-do:** no numeric detection ranges are stated for most systems; ask makers or find data sheets.
