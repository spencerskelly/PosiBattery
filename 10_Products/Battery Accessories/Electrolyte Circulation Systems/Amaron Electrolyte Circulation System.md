# Amaron Electrolyte Circulation System

## Definition

Optional electrolyte circulation system for Amaron Brute motive power cells.

## Notes

- The Amaron Brute brochure lists an Electrolyte Circulation System that "reduces water consumption by upto 60%" and "energy consumption by upto 20%" (maker claims, no test basis). Source: Amara Raja Amaron Brute brochure (T1, read through a summarizing tool), retrieved 2026-10-13. <https://www.amararajaeandm.com/amaron-brute/downloads/brochure.pdf>
- **Not stated:** the method (air injection or pump), part numbers, voltages, whether it is an option on every cell range (IB-181). No design is linked because the method is not named.
