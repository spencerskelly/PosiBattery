# Linde System Control

## Definition

Linde electronics on warehouse trucks that monitor the truck's potential to give the best simultaneous lift and travel speeds for the lift height and load.

## Notes

**Summary:**
Linde control system for VNA warehouse trucks that senses lift height and load to set optimum simultaneous lift and travel speeds.

**Marketed features:**
- Displays residual load capacity for the current lift height
- Stepless automatic speed adjustment by steering angle, lift height and load weight
- Automatic travel-speed reduction with platform raised (LSC 3.0)
- Optional load recognition (3.1), load sensor (3.2) and weight and load recognition (3.3)
- Marketed for higher throughput and enhanced safety
