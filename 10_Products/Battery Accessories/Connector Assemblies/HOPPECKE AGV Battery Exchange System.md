# HOPPECKE AGV Battery Exchange System

## Definition

Automated battery exchange installation for AGVs built by DIMOS with HOPPECKE trak uplift batteries, trak charger HF premium, trak collect and trak monitor 4.0.

## Notes

- Working name analyst-given (`unnamed-in-source`): a project story, not a catalog product. 18 batteries and 13 chargers for six trucks since April 2020. Source: <https://hoppecke.com/en/stories/show/completely-automated-operation-of-driverless-transport-systems> (T1, second-hand).
