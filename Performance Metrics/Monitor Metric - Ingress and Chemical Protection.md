# Monitor Metric - Ingress and Chemical Protection

## Definition

Ingress and Chemical Protection: Ingress rating and acid or spill resistance.

## Notes

- **Code and class:** MM12; monitor metric. Unit or format: IP rating; acid.
- **Comparability rule:** IP ratings and 'acid resistant' claims differ; only a stated IP code is comparable.
- **Direction:** higher IP is better.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[Advanced Charging Technologies BATTview]]: sealed, splash proof, UL 94V-5
  - [[EnerSys Wi-iQ]]: IP65; UL 94V-0; acid resistant
  - [[HOPPECKE trak collect]]: IP 69K; sulfuric acid 60% at 50 C
  - [[Philadelphia Scientific eGO!pro]]: IP65
  - [[PosiCharge Battery Rx]]: acid immersion and pressure-wash tolerance
  - [[PosiCharge PosiGuard]]: IP65 sealed against water and acid
  - [[Power Designers PowerTrac 3]]: water and acid resistant (no IP code)
  - [[Power Designers PowerTrac DT3]]: water and acid resistant (no IP code)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
