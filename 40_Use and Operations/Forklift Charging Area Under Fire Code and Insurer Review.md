# Forklift Charging Area Under Fire Code and Insurer Review

## Definition

Operating context in which a forklift charging area is judged by a fire authority (code adopted locally), a workplace safety regulator and the site's insurer, whatever its layout.

## Notes

- **Evidence status: analyst hypothesis, drafted 2026-10-17.** A cross-cutting overlay on [[Centralized Battery Room and Charging Area]] and [[Distributed and Opportunity Charging Area]]; it does not replace either.
- External rules and insurer guidance attached here are summarized in [[Lithium Forklift Charging Area Fire and Safety Code Register]]. Insurer items are guidance, not law.
- Which code edition applies depends on the local authority, which is unknown for any given site.
