# System

## Purpose

`99_System` contains the controlled MDSE runtime, authoring rules, schemas, templates, tools, and methodology-facing documentation used by the PosiBattery vault. It is infrastructure and governance, not product-model content.

## System areas

- `01_Admin` — controlled administrative/runtime support material.
- `02_AI` — AI instructions and authoring controls.
- `03_Schemas` — active element, relationship, metadata, author, and Local Model schemas.
- `04_People` — author identity records.
- `05_Templates` — governed model-note templates.
- `06_Fileclasses` — FileClass definitions used by Obsidian workflows.
- `08_Scripts` — runtime/support scripts.
- `09_Tools` — validation, reporting, migration, and maintenance tools.
- `10_Docs` — runtime and methodology-facing documentation.

## Navigation rule

Do not generate model-style Base/Canvas scaffolding for `99_System` merely for visual symmetry. This area is a compact governance/runtime tree; this README is its human entry point, while the numbered subfolders and linked authority documents provide the working navigation.

System files normally do not carry model `type` or `subtype` frontmatter. Product semantics belong in the numbered model domains, not here.
