# Metric - Watering Interval

## Definition

Watering Interval: Interval between refills for flooded batteries.

## Notes

- **Code and class:** BM04; battery metric. Unit or format: weeks or days.
- **Comparability rule:** Depends on charger and duty; 'working days' versus weeks differ.
- **Direction:** longer is better.
- **Values on file (as stated in each product note; n/s means not stated):**
  - [[Crown V-Force Lithium-Ion ESS]]: no watering (brochure: eliminates watering)
  - [[Deka HydraSaver Battery]]: ten weeks
  - [[Deka MaintenanceSaver Battery]]: four times a year
  - [[Exide MARATHON Battery]]: MARATHON Excell 16 weeks; 40 to 200 working days depending on type with GNB charging
  - [[Linde Ei Series]]: maintenance-free integrated lithium-ion battery
  - [[Raymond 8250 Lithium-Ion Battery]]: no watering, equalizing or cleaning
  - [[Stryten M-Series AGM200 Battery]]: never needs watering (valve-regulated)
  - [[Stryten M-Series T310 Battery]]: up to 90 days
  - [[Yale ERC050-060VGL]]: no battery maintenance (lithium-ion)
- **Source rule:** the product note holds the source URL for each value; this note copies the value for comparison. If they differ, the product note wins and this note is fixed.
- **Gaps and to-do:** 4 product(s) have a value; document-based values to be added as documents are supplied.
